# wallpaper-privacy

壁紙アプリのプライバシーポリシー・利用規約・特定商取引法に基づく表記・サポートページ（GitHub Pages）。

内容は wallpaper リポジトリのアプリ内文面（`wallpaper/Presentation/Settings/PrivacyPolicyView.swift`, `TermsOfServiceView.swift`）と同一にすること。

- https://g-session.github.io/wallpaper-privacy/support/ja/
- https://g-session.github.io/wallpaper-privacy/privacy/ja/
- https://g-session.github.io/wallpaper-privacy/terms/ja/
- https://g-session.github.io/wallpaper-privacy/tokushoho/ja/

## 2026-10-13 改定版

`privacy/2026-10-13/` にアプリ内文面と同じ改定版を用意する。日本語、英語（各国の追加事項を含む）、台湾・香港の繁体字中国語。1.2.0 の App Store ポリシー URL はこの改定版を参照する。既存の `privacy/ja/` は以前の版の参照先として保持する。

## 台湾向けサポート

- https://g-session.github.io/wallpaper-privacy/support/zh-Hant/

繁体字の使い方、購入・復元・返金の案内と問い合わせ先。1.3.0の台湾向け掲載に使用する。

## 2026-10-19 改定版

`privacy/2026-10-19/` に、共有メニューから受け取る写真の一時保存・投げ銭・背景設定の項目と、カナダの個人情報の責任者を追記した改定版を置く（日本語・英語・台湾・香港）。アプリ内文面（`wallpaper/Presentation/Settings/Legal/LegalDocument+PrivacyPolicy.swift`）と段落単位で一致を確認済み。次の版の App Store ポリシー URL はこちらを参照する。`privacy/2026-10-13/` は 1.5.0 までの参照先として保持する。

あわせて、利用規約（`terms/ja/`）と特定商取引法の表記（`tokushoho/ja/`）に投げ銭を追記し、サポートページを現行のアプリに合わせた。

- https://g-session.github.io/wallpaper-privacy/support/ja/
- https://g-session.github.io/wallpaper-privacy/support/en/ （英語圏5か国向け）
- https://g-session.github.io/wallpaper-privacy/support/zh-Hant/

## 2026-10-22 版（韓国語を追加）

`privacy/2026-10-22/` は 2026-10-19 版と同じ本文に、韓国語（`ko/`、個人情報保護法の記載事項を含む）を加え、各ページの言語切り替えに「한국어」を足したもの。韓国語ページはアプリ内文面（`LegalDocument+PrivacyPolicy.swift` の `koreanPrivacyPolicy`）から生成した。韓国向けのサポートページは `support/ko/`。
