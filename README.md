# wallpaper-privacy

壁紙アプリのプライバシーポリシー・利用規約・特定商取引法に基づく表記・サポートページ（GitHub Pages）。

内容は wallpaper リポジトリのアプリ内文面（`wallpaper/Presentation/Settings/PrivacyPolicyView.swift`, `TermsOfServiceView.swift`）と同一にすること。

- https://g-session.github.io/wallpaper-privacy/privacy/ja/
- https://g-session.github.io/wallpaper-privacy/terms/ja/

## 2026-10-13 改定版

`privacy/2026-10-13/` にアプリ内文面と同じ改定版を用意する。日本語、英語（各国の追加事項を含む）、台湾・香港の繁体字中国語。1.2.0 の App Store ポリシー URL はこの改定版を参照する。既存の `privacy/ja/` は以前の版の参照先として保持する。
